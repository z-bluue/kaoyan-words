# 我的生词本

考研英语生词管理 + 遗忘曲线复习，纯前端单文件应用，托管在 GitHub Pages。

打开网址即可使用，手机浏览器「添加到主屏幕」后像 App 一样打开。

## 功能

- **添加**：英文 + 释义，回车即加；支持批量粘贴（每行一个 `abandon 放弃`）。
- **重要度分档**：依据《红宝书》的「必考词 / 基础词 / 超纲词」章节自动标注
  - 必考词 1757 · 基础词 2968 · 超纲词 984，其余标「词表外」
  - 派生词（如 compensated → compensate）会回溯到原词分档
  - 复习队列按重要度排序，可在复习页切换「只看重点」
- **复习**：翻卡（先看英文→点卡片出释义→不认识 / 模糊 / 认识），按遗忘曲线排期
  - 认识：1 → 2 → 4 → 7 → 15 → 30 → 60 → 120 → 240 天
  - 模糊：间隔减半（新词 30 分钟）
  - 不认识：10 分钟后再来，并记一次错误
- **生词本**：搜索、按重要度/到期时间/错误次数排序，点词可改释义、重置进度、删除
- **统计**：总词数、待复习、今日新增、累计复习/错误、正确率、近 7 天复习柱状图、错得最多的词

## 数据

- 单词保存在**当前浏览器的 localStorage** 里，不上传服务器，换设备/换浏览器不互通。
- 「统计」页可导出 JSON 备份，换设备后导入即可合并。
- 清理浏览器数据会清空单词，建议定期导出。

## 本地开发

`index.html` 就是全部代码（无依赖、无构建）。改完直接提交，Pages 会自动更新。
